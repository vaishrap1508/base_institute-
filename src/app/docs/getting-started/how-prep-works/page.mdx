## The Placement Cycle

Successful placement preparation is not about cramming. It is a structured journey divided into four sequential milestones:

```mermaid
graph LR
    A[Milestone 1: Foundations] --> B[Milestone 2: Practice]
    B --> C[Milestone 3: Revision]
    C --> D[Milestone 4: Mock Phase]
```

### 1. Foundations Phase
* **Goal**: Understand core mathematical and logical formulas.
* **Metric**: Complete all prerequisite concept hub subtopics.
* **Study Asset**: Stored formulas sheets and initial notes.

### 2. Practice Phase
* **Goal**: Increase solving familiarity across varied question templates.
* **Metric**: Achieve at least 250 solved items with 80% accuracy.
* **Study Asset**: Bookmarked items with recorded shortcuts.

### 3. Revision Phase
* **Goal**: Consolidate shortcuts and verify reasoning on difficult topics.
* **Metric**: Empty your High Priority revision queue weekly.
* **Study Asset**: Completed customized folders.

### 4. Mock Phase
* **Goal**: Simulate high-stress exam environments.
* **Metric**: Pass 5 target company mock assessments under time limits.
* **Study Asset**: Performance reports showing percentile benchmarks.

## Core Preparation Workflow

For every concept domain, apply the following process to ensure long-term mastery:

```
[ Concept Lecture ]
        ↓
[ Solve 10 Basic Questions ] (Verify initial formula mapping)
        ↓
[ Solve 15 Company-specific Questions ] (Introduce target exam style)
        ↓
[ Note personal shortcuts ] (Identify time-savers)
        ↓
[ Run Timed Topic Quizzes ] (Verify speed under pressure)
```

## Common Placement Preparation Pitfalls

<Callout type="warning">
  **Pitfall: Memorizing solutions instead of patterns**  
  Many students read the editorial solution immediately after getting a question wrong. This creates a false sense of security. Always attempt solving for at least 60 seconds before seeking hints.
</Callout>

<Callout type="info">
  **Best Practice: Leverage the 100x Algebra Rule**  
  For percentage and interest questions, always assume the starting base is 100x. This eliminates decimals and prevents arithmetic errors that slow down your solve speed.
</Callout>
