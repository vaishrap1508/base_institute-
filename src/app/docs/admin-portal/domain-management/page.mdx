# Domain Management

The administrator's console to construct, modify, and coordinate the hierarchy of educational learning tracks.

---


## Overview

This page provides an overview and technical specifications for the Domain Management subsystem within the Kinetic Platform.

## Purpose
Domain Management allows administrators to manage course structures. It handles creating main domains, nesting subcategories, arranging sequence orders, and configuring prerequisite rules.

## Features
- **Tree-based Hierarchy Visualizer**: Interactive tree map displaying categories and sub-lessons.
- **Prerequisite Rules Console**: Configures completion rules required to unlock subsequent learning modules.
- **Registry Alignment Tool**: Ensures domains are registered under the central platform registry to prevent database conflicts.

## Data Sources
- **Domains Table**: Reads and writes fields like `id`, `name`, `description`, `parent_domain_id`, and `rules_config`.
- **Questions Table**: Counts total questions active under each domain category.

## User Actions
- **Add Domain Node**: Appends a new category or subcategory node, writing tracking parameters.
- **Reorder Nodes**: Drags and drops nodes to update sequencing values.

## Notes
> [!NOTE]
> Modifying parent domain linkages triggers automatic cascades to update nested child references.

---

## Architecture

This component is integrated into the Next.js and Supabase tier, responding dynamically to API endpoints and schema constraints.
