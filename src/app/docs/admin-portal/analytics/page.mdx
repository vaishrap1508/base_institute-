# Analytics & Reporting

The system dashboard displaying registration stats, portal activity, test performance, and question accuracy patterns.

---


## Overview

This page provides an overview and technical specifications for the Analytics & Reporting subsystem within Base Institute.

## Purpose
Analytics & Reporting provides insights into platform engagement and learning quality. It allows administrators to track user growth and identify questions that may have incorrect answers or formatting issues based on low accuracy scores.

## Features
- **Key Metrics Overview**: Real-time counters showing total signups, daily active users (DAU), active sessions, and test completions.
- **Competency Heatmaps**: Aggregated competency averages sorted by domain and demographic group.
- **Difficulty Index Analysis**: Detects questions with unusually low accuracy or high solution times.

## Data Sources
- **Profiles Table**: Provides signup counts, activity status, and demographic information.
- **Progress Table**: Gathers test accuracy, completion times, and overall XP logs.

## User Actions
- **Generate Report**: Generates and downloads a CSV report covering user performance or question accuracy.
- **Configure Telemetry**: Customizes data collection frequency and dashboard refresh rates.

## Notes
> [!NOTE]
> Detailed user activity data is updated hourly to keep the dashboard responsive and fast.
