# Create Question

The editor workspace for content creators to construct practice and assessment questions.

---


## Overview

This page provides an overview and technical specifications for the Create Question subsystem within the Kinetic Platform.

## Purpose
The Create Question interface allows writers to draft new test items. It provides tools for formatting, including LaTeX equation support, selecting correct answers, and writing detailed solutions.

## Features
- **Visual Markdown & LaTeX Editor**: Live preview side-by-side rendering of text and formulas using KaTeX.
- **Dynamic Options Panel**: Supports multiple-choice, select-all, and numeric entry answer patterns.
- **Automatic Solvers Check**: A background checker that solves written code/math equations to verify answer options match.

## Data Sources
- **Questions Table**: Inserts new rows with status `draft`.
- **Domains Table**: Reads valid categories and subcategories to assign appropriate link associations.

## User Actions
- **Add Answer Option**: Appends interactive selections, marking the correct answers.
- **Save Draft**: Commits current progress to the database without publishing it.

## Notes
> [!NOTE]
> All drafted questions are marked with `status = 'draft'` and must undergo administrator validation before going live.

This component is integrated into the Next.js and Supabase tier, responding dynamically to API endpoints and schema constraints.
