# Upload Video Explanation

The upload and management console for video explanations attached to questions.

---


## Overview

This page provides an overview and technical specifications for the Upload Video Explanation subsystem within Base Institute.

## Purpose
The Upload Video interface allows creators to attach video walkthroughs to questions. This gives students step-by-step visual guides for solving complex problems.

## Features
- **Drag-and-Drop Uploader**: Supports common formats (MP4, WebM) with automatic progress indicators.
- **Vimeo / YouTube Embed Integrations**: Allows embedding external links instead of hosting files directly.
- **Link Association Widget**: Quickly searches and links video assets to specific question IDs.

## Data Sources
- **Supabase Storage**: Stores raw video files in the designated public bucket.
- **Questions Table**: Updates the `video_url` column with the new video link.

## User Actions
- **Upload File**: Starts the chunked upload process to Supabase Storage, checking file type and size limits.
- **Link to Question**: Links the upload URL to a selected question, verifying status prior to saving.

## Notes
> [!IMPORTANT]
> Video uploads are limited to 50MB and should use H.264 compression to ensure fast playback on mobile networks.

---

## Architecture

This component is integrated into the Next.js and Supabase tier, responding dynamically to API endpoints and schema constraints.
