# User Management

The administrator's console to review profiles, manage user accounts, assign authorization roles, and audit login activity.

---


## Overview

This page provides an overview and technical specifications for the User Management subsystem within Base Institute.

## Purpose
User Management handles account control and administrative audits. Administrators search registered users, edit security clearances (Student, Content Creator, Admin), and address access issues.

## Features
- **User Directory Grid**: Features filters for role, registration date, active status, and cohort tags.
- **Security Console**: Revokes active JWT sessions, suspends profiles, and forces multi-factor authentication resets.
- **Activity Log Audit**: Tracks IP addresses, login timestamps, and critical administrative modifications.

## Data Sources
- **Profiles Table**: Updates role privileges (`role`), account status (`is_suspended`), and display settings.
- **Supabase Auth System**: Directly interfaces with Supabase's `auth.users` database schema.

## User Actions
- **Modify User Role**: Reassigns role metadata, triggering session validation updates.
- **Suspend / Reactivate Account**: Toggles active flags and terminates active user sessions.

## Notes
> [!WARNING]
> Changing standard user roles to Admin requires a dual-authorization token key to block privilege escalation.

---

## Architecture

This component is integrated into the Next.js and Supabase tier, responding dynamically to API endpoints and schema constraints.
