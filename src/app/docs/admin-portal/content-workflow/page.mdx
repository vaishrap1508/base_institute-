# Content Workflow

The editorial lifecycle outlining roles, collaboration patterns, approval policies, and content milestones.

---


## Overview

This page provides an overview and technical specifications for the Content Workflow subsystem within Base Institute.

## Purpose
The Content Workflow coordinates content creation. It outlines review handoffs, revision requirements, and final publication steps.

## Features
- **Review Cycle Framework**: Details the flow from draft generation to review validation, feedback loops, and final approval.
- **Role Assignment Table**: Guides task distribution (Writers, Editors, Admins) to maintain consistent publishing output.
- **SLA Tracking Dashboard**: Tracks the time questions spend in review to optimize processing times.

## Data Sources
- **Questions Table**: Updates state attributes (`status`) and editor metadata.
- **Comments Table**: Logs revision remarks and approval notes.

## User Actions
- **Assign Task**: Reassigns draft feedback tasks back to the content creator.
- **Archive Question**: Archives out-of-date or incorrect questions to clear the active directory.

## Notes
> [!NOTE]
> Questions that fail the automated LaTeX formatting check are automatically returned to the creator for revision.
