# Question Management

The central dashboard for administrators to review, approve, edit, and organize questions across all domains.

---


## Overview

This page provides an overview and technical specifications for the Question Management subsystem within Base Institute.

## Purpose
Question Management ensures that the platform maintains high educational and formatting standards. Administrators review creator submissions, correct mathematical formulas, adjust difficulties, and publish questions to the active directory.

## Features
- **Review Queue**: Lists newly drafted questions awaiting approval or revisions.
- **LaTeX Expression Editor**: A built-in compiler showing visual previews of formulas before changes are saved.
- **Question Tagging Console**: Assigns difficulty tags (Easy, Medium, Hard) and connects items to specific sub-domains.

## Data Sources
- **Questions Table**: Reads and writes question text, options, explanations, tags, and status logs.
- **Profiles Table**: Traces creator identities to attributes edits to the correct author.

## User Actions
- **Approve & Publish**: Changes status to `published`, making it active in practice and mock sets.
- **Request Revision**: Sets status to `draft` or `rejected`, sending feedback logs back to the content creator.

## Notes
> [!IMPORTANT]
> Once a question is linked to a mock exam session, it is locked and cannot be edited or deleted to prevent scoring errors.
