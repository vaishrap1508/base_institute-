## Discussion Drawer Hierarchy

To prevent screen transitions during practice, the **Discussion System** is contained inside a sliding drawer layout:
- **Comments Tab**: General questions about problem statements or alternate interpretations.
- **Peer Shortcuts Tab**: Voted shortcuts submitted by other students that optimize solve speeds.
- **Community Notes Tab**: High-quality structural breakdowns or formulas.
- **Tricks Tab**: Tricky alternate methods (e.g. working backwards from option choices).

```
+-----------------------------------------------------------+
| [Discussion Drawer]                                       |
|  [Comments]  [Peer Shortcuts]  [Community Notes]  [Tricks] |
+-----------------------------------------------------------+
| Upvoted Peer Shortcut:                                    |
| " CP = 100x, SP = 120x..." ▲ 25 Upvotes                   |
+-----------------------------------------------------------+
```

---

## Participating in Discussions

### 1. Finding Top Shortcuts
Sort comments by **Most Liked** to display community-verified tricks at the top of the feed.

### 2. Comment Guidelines
When posting comments:
- Avoid pasting direct answer key letters (e.g., "Answer is A"). Focus on explaining *why* it is A.
- Write formulas using standard markdown or LaTeX formatting to ensure clean KaTeX mathematical rendering.
