## Why the Practice Arena Layout Exists

Traditional platforms force you to load a new page for every action—solution checks, note logs, discussion inputs, and revisions. **AptiMaster Practice Arena** keeps everything inside a single, self-contained view:
- **Left Side (70%)**: Focus Workspace containing question breadcrumbs, stem text, options, and submission buttons.
- **Right Side (30%)**: Revision and Context Drawer (slides in on-demand).

This prevents context switching and maintains solving momentum.

### 1. Stopwatch Controls
- **Location**: Top right header.
- **Function**: Automatically tracks solve time from the moment the question loads.
- **Cycle**: Single click pauses the timer (masking the question stem to prevent cheating) and switches color to warning red/maroon-red. Click play to resume.

### 2. Answer Submission
- **Selecting**: Click option card (cards feature smooth hover lifts).
- **Evaluating**: Click the primary CTA "Submit". The system evaluates correctness, triggers a success confetti animation, logs attempt stats, and opens the solution tabs.

### 3. Keyboard Navigation Shortcuts
- `ArrowLeft`: Navigate to the previous question.
- `ArrowRight`: Navigate to the next question.

## Practice Arena Feature Guide

- **Purpose**: Build aptitude fluency through active solving.
- **Input**: Question Stem + Option Choice + Solve Duration.
- **Output**: Correction status + Stored solve log.
- **Common Mistake**: Selecting answers quickly to guess correctness.
- **Best Practice**: Attempt solving independently for 60 seconds before check submissions.
