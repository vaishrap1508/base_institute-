# Introduction

Welcome to the **Kinetic Platform** technical documentation. This guide serves as the single source of truth for the platform's architecture, data models, APIs, and portal interfaces.

---


## Overview

This page provides an overview and technical specifications for the Introduction subsystem within the Kinetic Platform.

## Purpose
The Kinetic Platform is a comprehensive, adaptive learning and skill assessment portal. It is designed to help students master various learning domains (e.g., quantitative aptitude, technical skills, logical reasoning) through interactive learning modules, practice arenas, and high-stakes mock tests, while providing robust administration, content-creation, and analytics workflows for administrators and content creators.

## Features
- **Adaptive Learning Engine**: Tailors lesson delivery and practice difficulties to individual student capabilities.
- **Role-based Portal Interfaces**: Separate, optimized dashboards for Students, Content Creators, and Administrators.
- **Real-time Performance Analytics**: Dynamic tracking of streaks, domain mastery, peer comparisons, and mock test telemetry.
- **Robust Schema Registry**: Relies on a unified identifier registry to ensure absolute consistency across all core database entities.

## Data Sources
- **Unified ID Registry**: Reads from the ID Registry configuration to correlate domains, questions, and progress tracking.
- **Configuration**: Uses system environment parameters (`.env` configurations) for database connecting and API routing.

## User Actions
- **Accessing the Portal**: Handled via global path resolution based on authenticated user roles (Admin, Student, Creator).
- **Theme Selection**: Toggle between system, light, and dark UI themes dynamically.

## Notes
> [!IMPORTANT]
> The platform is built on **Next.js 16 (App Router)** and **Supabase (PostgreSQL)**, utilising row-level security (RLS) to strictly isolate tenant and role data.
