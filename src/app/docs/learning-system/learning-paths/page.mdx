## What is a Learning Path?

A **Learning Path** is a sequential roadmap mapping a curriculum domain from basic foundations to high-level certification. Instead of selecting random topics, paths keep you focused on a progressive study sequence.

---

## Anatomy of the Path Roadmap

Each domain features a timeline composed of concept nodes, checkpoints, and a final certification challenge:

```
[ Concept 1 ] ──► [ Concept 2 ] ──► [ Checkpoint 1 ] ──► [ Concept 3 ] ──► [ Certification ]
```

### 1. Concept Nodes
- **Action**: Read the formula sheet, complete 10 topic solved items.
- **Goal**: Build basic formula familiarity.

### 2. Checkpoint Challenges
- **Action**: Timed, multi-topic mini-quiz testing retention of the preceding segment.
- **Goal**: Lock in memory patterns.

### 3. Certification Gates
- **Action**: Comprehensive evaluation covering all domain subtopics.
- **Goal**: Pass with `>= 75%` to display the verified domain badge on your profile.

---

## Service vs Product Pathways

Select the path that matches your target goal:

### Service Qualifier Path
- **Focus**: Quantitative ratios, logical puzzles, verbal error spotting.
- **Sequence**: Percentages ➔ Ratios ➔ Series ➔ Syllogisms ➔ Grammar ➔ Certification.

### Product Tech Path
- **Focus**: Algorithmic complexity, advanced probability, logical matrices.
- **Sequence**: Array indexing ➔ Recursion ➔ OOP ➔ Data Structures ➔ Algorithms ➔ Certification.

## Best Practices for Roadmap Study

<Callout type="info">
  **Best Practice: Focus on a Single Path**  
  Avoid hopping between quantitative and coding paths mid-week. Focus on finishing one domain roadmap to 50% completion before initiating a secondary path. This keeps concepts contiguous in your memory.
</Callout>

<Callout type="warning">
  **Warning: Checkpoint Expiry**  
  If you fail a Checkpoint Challenge twice, the system locks progress on the path for 12 hours, advising you to practice basic questions in the Practice Arena first. Use this window to review your saved notes.
</Callout>
