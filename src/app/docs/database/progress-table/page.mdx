# Study Progress & Telemetry Tables

Technical specifications for progress logs, study sessions, question attempts, and bookmarks.

---


## Overview

This page provides an overview and technical specifications for the Study Progress & Telemetry Tables subsystem within the Kinetic Platform.

## Purpose
These tables track student learning data, including active streaks, completed lessons, bookmarks, and detailed question accuracy statistics.

---

## Table Schemas

### 1. public.user_streaks
Tracks consecutive study days:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `user_id` | `uuid` | `PRIMARY KEY`, `FK` | - | References `profiles.id` (`ON DELETE CASCADE`). |
| `current_streak` | `integer` | `NOT NULL` | `0` | Active daily streak count. |
| `max_streak` | `integer` | `NOT NULL` | `0` | All-time highest streak count. |
| `last_activity_at`| `timestamptz` | `NOT NULL` | `now()` | Timestamp of last user action. |

### 2. public.user_progress
Records completed questions:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `gen_random_uuid()` | Unique primary key for the log. |
| `user_id` | `uuid` | `FOREIGN KEY` | - | References `profiles.id` (`ON DELETE CASCADE`). |
| `question_id` | `varchar(23)` | `FOREIGN KEY` | - | References `questions.id` (`ON DELETE CASCADE`). |
| `is_solved` | `boolean` | `NOT NULL` | `false` | Solved state. |
| `solved_at` | `timestamptz` | `NOT NULL` | `now()` | Timestamp when solved. |
| `solve_time_ms` | `integer` | - | `NULL` | Time spent in milliseconds. |

- *Unique Constraint*: `user_id` and `question_id` must be unique to prevent duplicate logs.

### 3. public.progress_tracking
Tracks overall concept completion status:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `gen_random_uuid()` | Unique primary key. |
| `user_id` | `uuid` | `FOREIGN KEY` | - | References `profiles.id` (`ON DELETE CASCADE`). |
| `concept_id` | `uuid` | `FOREIGN KEY` | - | References `concepts.id` (`ON DELETE CASCADE`). |
| `progress_percent`| `integer` | `NOT NULL` | `0` | Progress completion percentage. |
| `status` | `text` | `NOT NULL` | `'Locked'` | Must be `'Locked'`, `'In Progress'`, or `'Completed'`. |
| `updated_at` | `timestamptz` | `NOT NULL` | `now()` | Last update timestamp. |

- *Unique Constraint*: `user_id` and `concept_id` must be unique to prevent duplicate logs.

### 4. public.user_bookmarks
Stores bookmarked questions:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `gen_random_uuid()` | Unique primary key. |
| `user_id` | `uuid` | `FOREIGN KEY` | - | References `profiles.id` (`ON DELETE CASCADE`). |
| `question_id` | `varchar(23)` | `FOREIGN KEY` | - | References `questions.id` (`ON DELETE CASCADE`). |
| `folder_name` | `text` | - | `'General'` | Folder name for organizing bookmarks. |
| `note_md` | `text` | - | `NULL` | Optional markdown notes. |
| `created_at` | `timestamptz` | `NOT NULL` | `now()` | Bookmark creation timestamp. |

## Used By Screens
- **Student Dashboard**: Updates daily streaks, calculates competency averages, and displays recent logs.
- **Learning Roadmap**: Highlights completed nodes and locks subsequent sub-topics based on progress.
- **Profile & Achievements**: Displays earned badges based on milestones and plots study charts.
