# Domains & Topics Tables

Technical specifications for the `domains`, `sub_topics`, and `concepts` tables that construct the learning hierarchy.

---


## Overview

This page provides an overview and technical specifications for the Domains & Topics Tables subsystem within the Kinetic Platform.

## Purpose
These tables define the course structure (Domain -> Sub-topic -> Concept) and support dynamic course roadmaps and progress tracking.

---

## Table Schemas

### 1. public.domains
Stores top-level course categories:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `gen_random_uuid()` | Unique primary key for the domain. |
| `name` | `text` | `UNIQUE`, `NOT NULL`| - | Subject name (e.g. Quantitative Aptitude). |
| `created_at` | `timestamptz` | `NOT NULL` | `now()` | Creation timestamp. |

### 2. public.sub_topics
Stores nested sub-topics:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `gen_random_uuid()` | Unique primary key for the sub-topic. |
| `domain_id` | `uuid` | `FOREIGN KEY` | - | References `domains.id` (`ON DELETE CASCADE`). |
| `name` | `text` | `NOT NULL` | - | Sub-topic name (e.g. Algebra). |
| `created_at` | `timestamptz` | `NOT NULL` | `now()` | Creation timestamp. |

- *Unique Constraint*: `domain_id` and `name` must be unique to prevent duplicates.

### 3. public.concepts
Individual learning nodes containing course content and videos:

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `gen_random_uuid()` | Unique primary key for the concept. |
| `sub_topic_id` | `uuid` | `FOREIGN KEY` | - | References `sub_topics.id` (`ON DELETE CASCADE`). |
| `name` | `text` | `NOT NULL` | - | Concept name (e.g. Quadratic Equations). |
| `video_url` | `text` | - | `NULL` | Video explanation link. |
| `created_at` | `timestamptz` | `NOT NULL` | `now()` | Creation timestamp. |

- *Unique Constraint*: `sub_topic_id` and `name` must be unique to prevent duplicates.

---

## Used By Screens
- **Domains Directory**: Populates the bento domain grids and subcategory selections.
- **Learning Roadmap**: Displays the chronological list of sub-topics and concept nodes.

> [!NOTE]
> Deleting a parent domain automatically cascades down, deleting all associated sub-topics and concepts.
