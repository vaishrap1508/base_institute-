# Profiles Table

Technical specifications for the `public.profiles` table, storing core user metadata.

---


## Overview

This page provides an overview and technical specifications for the Profiles Table subsystem within the Kinetic Platform.

## Purpose
The `profiles` table stores user details, account roles, and daily learning streak configurations. It links credentials directly with user progress and analytics tables.

---

## Column Specifications

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `uuid` | `PRIMARY KEY` | `auth.uid()` | Matches the user's primary credentials ID. |
| `username` | `text` | `UNIQUE` | `NULL` | The user's chosen username. |
| `full_name` | `text` | - | `NULL` | The user's full name. |
| `email` | `text` | `UNIQUE`, `NOT NULL` | - | Primary contact and verification email. |
| `phone` | `text` | - | `NULL` | Optional phone contact number. |
| `college` | `text` | - | `NULL` | College name. |
| `branch` | `text` | - | `NULL` | Academic degree branch. |
| `grad_year` | `integer` | - | `NULL` | Graduation year. |
| `role` | `user_role` | `NOT NULL` | `'STUDENT'` | Access role (Student, Admin). |
| `created_at` | `timestamptz` | `NOT NULL` | `now()` | Timestamp of account registration. |
| `updated_at` | `timestamptz` | `NOT NULL` | `now()` | Timestamp of the last profile modification. |

---

## Database Triggers
- **`on_auth_user_created`**: Executes `handle_new_user()` after an insert on `auth.users`. It automatically duplicates metadata, emails, and roles to this table.

---

## Used By Screens
- **Student Dashboard**: Displays full name, degree branch, and email details.
- **Onboarding Questionnaire**: Populates profile fields (college, branch, graduation year).
- **Leaderboards**: Displays display name and avatar details.
- **Admin Directory**: Allows administrators to view user roles and status values.

> [!NOTE]
> Database triggers automatically create a profile row when a new user registers through the onboarding flow.
