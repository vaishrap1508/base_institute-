# Migrations History

Technical reference documenting the evolution of the database structure across the platform's migration scripts.

---


## Overview

This page provides an overview and technical specifications for the Migrations History subsystem within the Kinetic Platform.

## Purpose
The Migrations history tracks schema changes over time. It details historical SQL scripts and outlines steps for deploying updates.

## Deployment Workflow
To deploy schema modifications:
1. **Create Migration**: Run `supabase migration new [description]` to create a new SQL file.
2. **Apply Locally**: Run `supabase db reset` to reset the local database and apply migrations.
3. **Deploy to Production**: Run `supabase db push` to deploy migrations to the production environment.

> [!WARNING]
> Do not modify existing migration files (`00000` to `00012`) directly. Any changes must be added as a new migration file to prevent sync errors.
