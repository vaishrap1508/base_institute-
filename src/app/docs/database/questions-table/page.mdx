# Questions Table

Technical specifications for the `questions` table and the custom triggers that generate unique visual alphanumeric IDs.

---


## Overview

This page provides an overview and technical specifications for the Questions Table subsystem within the Kinetic Platform.

## Purpose
The `questions` table stores question content, options, answers, solutions, and category linkages. It serves as the data foundation for the Practice Arena and Mock Test modules.

---

## Column Specifications

| Column Name | Data Type | Constraint | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `varchar(23)` | `PRIMARY KEY` | - | Generated alphanumeric ID. |
| `concept_id` | `uuid` | `FOREIGN KEY` | `NULL` | References `concepts.id` (`ON DELETE SET NULL`). |
| `type` | `question_type`| `NOT NULL` | `'MCQ'` | MCQ, Coding, or Short Answer. |
| `difficulty` | `difficulty_level`| `NOT NULL` | `'MEDIUM'` | Easy, Medium, or Hard. |
| `question_text` | `text` | `NOT NULL` | - | Question body (supports LaTeX). |
| `options` | `jsonb` | - | `NULL` | Array of options containing IDs and text. |
| `correct_answer`| `text` | `NOT NULL` | - | Key or index matching the correct option. |
| `explanation` | `text` | - | `NULL` | Detailed text solution (supports LaTeX). |
| `video_url` | `text` | - | `NULL` | Video explanation link. |
| `is_active` | `boolean` | `NOT NULL` | `true` | Active questions visible in practice sets. |
| `created_by` | `uuid` | `FOREIGN KEY` | `NULL` | References `profiles.id` to track the creator. |
| `created_at` | `timestamptz` | `NOT NULL` | `now()` | Creation timestamp. |
| `updated_at` | `timestamptz` | `NOT NULL` | `now()` | Last update timestamp. |

## Unified Visual ID Generation Trigger
When a question is added, database triggers calculate a custom 23-character visual ID instead of a standard UUID:
- **Trigger**: `trigger_generate_questions_unified_id` runs `generate_questions_unified_id()` before inserts or updates.
- **Visual Format**: `BBBB[Letter]-BBBB[Letter]-BBBB[Letter]-BBBB[Letter]`
- **Calculation Logic**:
  - **Block 1**: Represents the alphabetical position index of the parent Domain.
  - **Block 2**: Represents the alphabetical position index of the Sub-topic within that Domain.
  - **Block 3**: Represents the alphabetical position index of the Concept within that Sub-topic.
  - **Block 4**: Tracks the creation sequence number of the question under that Concept.
- **Conversion Math**: Converts integers to 4-digit binary strings and appends Crockford alphabet characters (`ABCDEFGHJKMNPQRT`) to ensure unique IDs.

## Used By Screens
- **Practice Arena**: Loads question text, choices, and solutions.
- **Mock Tests**: Groups questions into timed assessments.
- **Content Creator Workspace**: Interface for creating and editing questions.

> [!IMPORTANT]
> The database trigger generates question IDs automatically. Manually specifying question IDs during inserts is not supported and will be overridden by the trigger.
