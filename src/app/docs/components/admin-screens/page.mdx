# Admin Panel Screens

This section details the primary route panels in the Administrative Workspace, outlining the purpose, states, API dependencies, and layout of each admin screen.

---


## Overview

This page provides an overview and technical specifications for the Admin Panel Screens subsystem within Base Institute.

## 1. Overview Dashboard

The main portal for administrators summarizing system health, editorial queues, and student solving trends.

### Purpose
Aggregates telemetry data to show overall content health, pending questions, active user cohorts, and recent system audit logs.

### Location in Codebase
- File: [src/app/admin/dashboard/page.tsx](file:///Users/vaishu/Downloads/Base_Project/src/app/admin/dashboard/page.tsx)

### State Management & Layout Cards
- **Overview Stat Cards**: Four high-level metric panels displaying total questions, pending review count, total registered students, and average system accuracy ratings.
- **Activity Log Stream**: Tabulated rows displaying recent actions (e.g. "VAISHNAVI RAPARTHY updated Q-8029-X").

---

## 2. Editor Workspace

The content editing workspace placing the visual markdown editor and responsive device simulator side-by-side.

### Purpose
Coordinates authoring input flows, validation rules, option mappings, and Supabase integration updates.

### Location in Codebase
- File: [src/app/admin/editor/page.tsx](file:///Users/vaishu/Downloads/Base_Project/src/app/admin/editor/page.tsx)

### State Management
- `activeQuestion` (`Question | null`): Holds the currently selected question record, loaded from route queries or table selections.
- `validationErrors` (`string[]`): Dynamically populated error lists enforcing check constraints (e.g. requires at least one correct option, text stem length must be `> 10` characters).

### API & Database Dependencies
- `POST /api/questions/save`: Saves new question entries.
- `PUT /api/questions/update/[id]`: Updates details of an existing question.
