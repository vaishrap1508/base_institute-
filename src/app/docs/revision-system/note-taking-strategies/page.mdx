Learn how to write high-quality shortcuts, structure equations using KaTeX math notation, and organize revision notes.

## Why Custom Notes Matter

Textbooks contain general explanations, but they don't capture your personal logic shortcuts. Writing a **custom note** ensures that when you revisit a problem, you immediately recall *how your brain solved it*.

Candidates who log custom shortcuts on wrong attempts achieve **40% higher retention** on subsequent reviews compared to passive editorial readers.

---

## The Markdown & KaTeX Note Template

Structure your notes to maximize review speed. We recommend this layout:

### 1. The Core Trap (Why you got it wrong)
Identify the mistake (e.g. *"Forgot that seating is circular, so directions flip"*).

### 2. The Speed Shortcut (Mathematical shorthand)
Use KaTeX math block syntax:
```latex
$$\text{Ratio of Speeds} \propto \frac{1}{\text{Time taken}}$$
```
Renders as:
$$\text{Ratio of Speeds} \propto \frac{1}{\text{Time taken}}$$

### 3. The Test Verification
List how to check if the answer is logical:
- Ensure the ratio values are small positive numbers.
- Verify options by checking if they divide the total sum.

## Formatting Diagrams in Text

For logical reasoning topics (like seating arrangements), draft layout outlines using simple text tables or characters:

```
    [A]
[F]     [B]   <-- Circular arrangement outline
[E]     [C]
    [D]
```

This simple map is easily rendered in your markdown card and provides an immediate visual clue on review.
