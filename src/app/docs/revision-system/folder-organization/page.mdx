## The Folder Hierarchy Strategy

A disorganized bookmarks pool is rarely used. Grouping questions into **Folders** prepares you to study specific subtopic methods:

```
[ All Stored Bookmarks ]
   ├──► 📂 [ Arithmetic Shortcuts ]  (Formula speed notes)
   ├──► 📂 [ TCS NQT Prep ]          (Target company style)
   ├──► 📂 [ Infosys Logic ]         (Sequencing matrixes)
   └──► 📂 [ Geometry Formulas ]     (Shape proofs)
```

### 1. Default System Folders
- **All Saved**: Master list containing all bookmarked items.
- **Without Notes**: Questions saved without custom note shortcuts.

### 2. Custom Folders
Create custom directories matching your placement timeline:
* `+ Create New Folder` from the Quick Save drawer.
- System dynamically updates counts (e.g. `📂 TCS NQT Prep (14)`).

## Common Folder Mapping Strategies

Use this mapping scheme depending on your active target:

| Target Goal | Suggested Folder Name | Focus Content | Typical Review Cycle |
| :--- | :--- | :--- | :--- |
| **Speed Building** | `Arithmetic Shortcuts` | Percentage fractions, work equations | Twice / week |
| **Recruiter Qualifier** | `TCS NQT Prep` | Basic quant, logical sequences | Weekly |
| **Logic & Visuals** | `Infosys Logic` | circular arrays, syllogisms | Once / 2 weeks |
| **Formulas Sheet** | `Geometry Formulas` | mensuration, area algebra | Daily review |

## Folder Best Practices

<Callout type="info">
  **Best Practice: Keep folders focused**  
  Do not create more than 5 custom folders. Too many folders create visual clutter in the Revision Library sidebar. Group by recruiter profile or primary subject domain (Quant vs Coding) for clarity.
</Callout>

<Callout type="warning">
  **Warning: Empty Folder Clean-up**  
  Removing the last bookmarked question from a custom folder does not delete the folder from local database configurations. Audits can be run in Settings to clear empty folders.
</Callout>
