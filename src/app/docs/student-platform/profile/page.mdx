# Profile & Achievements

The student profile workspace, displaying performance analytics, earned badges, and account configurations.

---


## Purpose

The main purpose of this module is to ensure system responsiveness, coordinate client events, and maintain relational integrity across data stores.

## Overview & Purpose
The Profile page displays a student's personal details, target career paths, earned badges, and overall learning activity history.

---

## Key Features

### 1. 3D Achievement Badges Gallery
- Displays all earned achievements, like **First Step**, **Getting Started**, and **Early Bird**.
- **Interactive Details**: Clicking a badge displays requirements and active completion progress.
- **Visuals**: Uses 3D card tilt effects and flood-fill image transparency processing to display badges cleanly.

### 2. Activity Telemetry Charts
- Displays study logs using line and bar charts tracking XP gains, daily lesson completions, and active hours.

### 3. Account Settings
- Form fields allowing students to update their display name, degree branch, graduation year, and select custom adventurer profile avatars.

---

## Database Schema
- **`public.profiles`**: Stores profile settings (`full_name`, `college`, `branch`, `grad_year`).
- **`public.user_badges`**: Tracks unlocked badges, linking user IDs to the `badges` table.
- **`public.user_progress`**: Aggregates question attempts to display performance trends.

---

## Architecture

This component is integrated into the Next.js and Supabase tier, responding dynamically to API endpoints and schema constraints.
