# Career Hub

The career placement portal connecting student competency data directly with job profiles, internship listings, and corporate recruitment opportunities.

---


## Purpose

The main purpose of this module is to ensure system responsiveness, coordinate client events, and maintain relational integrity across data stores.

## Overview & Purpose
The Career Hub is located as a tab within the dashboard, displaying listings from the `opportunities` database. It connects a student's domain mastery directly with hiring requirements, allowing qualified candidates to apply for jobs and internships.

---

## Key Features

### 1. Curated Opportunity Catalog
- Matches students with job categories like **Hiring Drives**, **Internships**, **Government Exams**, **Hackathons**, and **Webinars**.
- Dynamically filters listings to prioritize open roles, with tags like `Closing Soon`, `New`, or `Open`.

### 2. Placement Announcements
- Integrates with the `announcements` database, letting administrators publish high-priority alerts (e.g. Goldman Sachs simulation schedules) that pin directly to the top of the feed.

### 3. Eligibility Verification
- Prior to showing external application URLs, the client compares the student's domain competency scores with requirements (e.g., a candidate needs >= 75% coding competency to apply for a software engineering drive).

---

## Database Schema
- **`public.opportunities`**: Stores metadata like `title`, `organization`, `type`, `deadline`, `status`, and `link`.
- **`public.announcements`**: Stores administrator alerts, types, priority levels, and publisher names.

> [!NOTE]
> Career opportunity listings are updated via database synchronization routines, keeping listings fresh and matching them with current recruiter needs.

---

## Architecture

This component is integrated into the Next.js and Supabase tier, responding dynamically to API endpoints and schema constraints.
