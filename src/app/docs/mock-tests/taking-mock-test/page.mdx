## Why Mock Tests Matter

Solving questions individually build accuracy, but it doesn't prepare you for **exam fatigue** and **timed pressure**.
- **Mock Assessments**: Simulates the exact constraints (e.g. 40 questions in 45 minutes) of target recruiters.
- **Milestone Gaps**: Mock performance reports expose topic gaps that don't stand out during basic practice sessions.

---

## Mock Exam Interface Flow

```
[ Start Exam ] ──► [ Instructions Gate ] ──► [ Section 1: Quantitative ] ──► [ Section 2: Logical ] ──► [ Final Submit ]
```

### 1. The Instructions Gate
Verify camera settings, review section timings, and click "I am ready to begin". Once clicked, the master countdown timer starts and cannot be paused.

### 2. Multi-Section Structure
- **Section 1: Quantitative Aptitude**: Numerical equations.
- **Section 2: Logical Reasoning**: Sequence and matrix problems.
- **Section 3: Verbal Ability**: Grammar check pages.

---

## Exam Navigation Shortcuts

- **Mark for Review**: Tag a question to review before final submission. It appears yellow on the questions map index.
- **Jump Panel**: Right-side layout grids listing all question status markers (Pending, Solved, Marked).

---

## Mock Test Best Practices

<Callout type="info">
  **Best Practice: Attempt easy questions first**  
  Do not spend more than 90 seconds on a single question. If a problem is too complex, click **Mark for Review** and skip it. Secure the easy marks first before wrestling with hard calculations.
</Callout>

<Callout type="warning">
  **Warning: Window Switching Rules**  
  Leaving the exam tab or switching browser windows triggers warning flags. Hitting 3 warning flags will automatically submit your exam sheet, locking the score.
</Callout>
