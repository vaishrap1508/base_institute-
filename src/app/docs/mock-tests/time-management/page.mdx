## The Three-Pass Strategy

The single highest factor in failing timed aptitude assessments is poor pacing. Do not solve questions in linear order. Apply the **Three-Pass Strategy**:

```
[ Pass 1: Quick Solves ] (0s - 45s) ──► Solve obvious formula matches
        ↓
[ Pass 2: Calculation Items ] (45s - 90s) ──► Solve familiar multi-step problems
        ↓
[ Pass 3: Hard / Skip ] (90s+) ──► Wrestle with remaining complex puzzles
```

### Pass 1: Core Formula Matches
- **Goal**: Lock in easy points. Skip any question requiring complex algebra setup immediately.

### Pass 2: Familiar Calculations
- **Goal**: Address medium-difficulty questions where you understand the formula but require scratchpad workspace time to calculate.

### Pass 3: Tricky / Time-Sink Items
- **Goal**: Address remaining items. If a question exceeds 120 seconds, select your best guess and submit.

## Time Management Best Practices

<Callout type="info">
  **Best Practice: Establish a Hard-Skip Threshold**  
  Define a strict cutoff time (e.g., 90 seconds). If you have not established the final equation by 90 seconds, flag the question for review, select an option, and move on.
</Callout>

<Callout type="warning">
  **Warning: Final Rush Penalty**  
  Rushing through the last 5 questions of a section because of poor pacing leads to careless mistakes on easy questions. Keep an eye on the header stopwatch and adjust speed early.
</Callout>
