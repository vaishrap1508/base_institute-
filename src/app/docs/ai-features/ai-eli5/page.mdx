## Why ELI5 Exists

Many students struggle with aptitude concepts because they are explained using dry mathematical formulas. The **AI ELI5 (Explain Like I'm 5)** engine resolves this by mapping abstract concepts to physical, everyday operations:
- **Profit and Loss** ➔ Cookie baking and school fair selling.
- **Ratios** ➔ Slicing pizzas or sharing candy.
- **Speed & Distance** ➔ A race between a tortoise and a rabbit.

---

## Prompt Template Configuration

When you click "AI ELI5", the backend invokes a specialized prompt template:

```
Role: You are a friendly, highly visual mathematics tutor.
Task: Explain the following question stem and solution using:
1. An everyday analogy (e.g. cookies, candy, trains).
2. A single-sentence mathematical speed shortcut.
3. An exam tip focused on common traps.
Constraint: Avoid dry algebraic symbols. Keep instructions simple.
```

---

## ELI5 Interaction Guide

- **Trigger**: Click the **AI ELI5** tab next to Video Solutions.
- **Inputs**: Active Question ID, Question Stem, correct option choice.
- **Output**: Simplified breakdown containing:
  - 🍪 **Analogy**: Real-world visual map.
  - ⚡ **Speed Shortcut**: Algebraic simplification.
  - 🎓 **Exam Tip**: Recruiter trap warnings.

## AI ELI5 Best Practices

<Callout type="info">
  **Best Practice: Save the AI Tip instantly**  
  Click the **Save Shortcut** link below the ELI5 response. This automatically appends the summary to your **My Notes** editor for the active question, displaying it on the personal shortcut card.
</Callout>

<Callout type="warning">
  **Warning: Use for new topics**  
  Do not rely on ELI5 for revision phase study. Use it when learning a topic for the first time to build intuitive understanding. Transition to text/video formulas as you build speed.
</Callout>
