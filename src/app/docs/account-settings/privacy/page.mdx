## Profile Visibility Levels

Our platform provides four privacy settings:

### 1. Public Mode
- **Visibility**: Anyone can view your profile page, completed badges, activity heatmaps, and readiness radar.
- **Leaderboards**: Fully visible with name and college tags.

### 2. Recruiter Visible Mode (Recommended)
- **Visibility**: Only verified partner recruitment managers and platform administrators can view your details.
- **Leaderboards**: Displayed as anonymous values (e.g. `Candidate #3402`).

### 3. Friends Only Mode
- **Visibility**: Restricted to students in your same university cohort or batch.

### 4. Private Mode
- **Visibility**: Completely restricted. Only you can view your progress reports and profile cards.
- **Leaderboards**: Completely hidden from all listings.

## Row-Level Security (RLS) Integration

Privacy settings are enforced at the database query layer:

```
[ Client Query Profile ] ➔ [ Supabase RLS Evaluator ] ➔ Check target visibility state
                                                             │
                                                             ├──► Private ➔ Reject query
                                                             └──► Recruiter Visible ➔ Match Role
```

## Privacy Best Practices

<Callout type="info">
  **Best Practice: Use Recruiter Visible to secure job matches**  
  Keep profile visibility set to **Recruiter Visible**. This keeps your stats hidden from public Google searches while ensuring placement cells can filter your skills for target recruitment drives.
</Callout>

<Callout type="warning">
  **Warning: CGPA Privacy**  
  Regardless of visibility settings, your numerical CGPA and rank indices are never displayed publicly. Recruiters view them as qualifying checkmarks (e.g. `CGPA Criterion Met`).
</Callout>
