## Academic Credentials Architecture

Your profile links university enrollment parameters directly to company-specific placement matching logic:

```
[ Update Credentials Form ] ──► [ Schema Validation ] ──► [ Upsert to profiles table ]
                                                                 │
                                                                 └──► [ Matches Recruiter eligibility filters ]
```

### 1. Graduation batch
Used to group leaderboards and mock test analysis reports by target years.

### 2. Branch and University CGPA
Required metric criteria for matching product recruiter qualifications (e.g. *CGPA cutoff >= 8.0*).

## Form Submission Best Practices

<Callout type="info">
  **Best Practice: Verify CGPA updates immediately**  
  When you finish a semester, update your CGPA. High accuracy on mock tests doesn't qualify you for recruiter lists if your registered CGPA is below their threshold limits.
</Callout>

<Callout type="warning">
  **Warning: Case-sensitive Emails**  
  Registration email profiles are converted to lowercase. Capital letters are rejected in auth submit routes to prevent account duplication conflicts.
</Callout>
