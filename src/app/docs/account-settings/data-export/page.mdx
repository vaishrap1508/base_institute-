## Why Data Export Exists

To guarantee immediate page responsiveness, your shortcuts, folders, and priorities are cached locally in your browser's `localStorage` (`aptitude_revision_db`). 

However, local caches can be wiped if you clear your browser history or use private browsing. **Data Export** allows you to download a backup file of your revision progress.

---

## The Export-Import Lifecycle

```
[ Active Notes Cache ] ──► [ Click Export Data ] ──► [ Download revision_backup.json ]
                                                             │
[ Clear Browser Cache ] ◄── [ Import Backup File ] ◄─────────┘
```

### 1. Exporting Data
Click **Export Revision Database** in settings. The system compiles your notes, folders, and priority logs into a single structured JSON payload file.

### 2. Importing Data
Select **Upload Backup JSON** to restore your revision library, folders, and metrics on a new machine or secondary browser.

---

## Data Export Best Practices

<Callout type="info">
  **Best Practice: Export your notes monthly**  
  If you have logged more than 50 custom shortcut notes, download a backup copy. Storing the JSON file on your Google Drive ensures you never lose your revision assets.
</Callout>

<Callout type="warning">
  **Warning: Backup Payload Compatibility**  
  Do not modify the keys inside the exported JSON file manually. Changing structure tags can lead to verification failures when uploading the backup file.
</Callout>
