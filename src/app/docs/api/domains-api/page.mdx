# Domains API

This page provides specifications for the domain catalog directory retrieval and student learning path enrollment endpoints.

---

## Overview

The Domains API exposes the structured taxonomy tree of learning modules. It handles student enrollment, computes progress percentages, and unlocks child topics based on academic competency thresholds.

## Purpose

The domains endpoints deliver navigation structure to frontend roadmaps. Tracking enrollment progress dynamically ensures that students see visual roadmap progress and recommendation highlights.

## Architecture / Flow

Catalog endpoints query database trees, returning subtopics arrays nested under domains. Enrollment writes progress tracker records mapped to student sessions.

---

## Endpoints

### 1. Get Domain Directory Catalog
Retrieves the complete catalog of domains, including subtopics and concept nodes, along with the student's active progress metrics.

- **Endpoint**: `/api/student/domains`
- **Method**: `GET`
- **Authentication Requirements**: Valid Student Session Cookie
- **Rate Limit**: 120 requests per minute.

#### Example Request & Response
```bash
# GET /api/student/domains
```

```json
// Response 200 OK
[
  {
    "id": "dom_quant",
    "name": "Quantitative Aptitude",
    "progress_percent": 75,
    "sub_topics": [
      {
        "id": "sub_algebra",
        "name": "Algebra",
        "concepts": [
          { "id": "con_quadratic", "name": "Quadratic Equations", "status": "Completed" }
        ]
      }
    ]
  }
]
```

### 2. Enroll in Domain Path
Enrolls a student in a learning path, creating progress tracking records for each concept node.

- **Endpoint**: `/api/student/domains/enroll`
- **Method**: `POST`
- **Authentication Requirements**: Valid Student Session Cookie
- **Rate Limit**: 10 requests per minute.
- **Request Body**:
  - `domain_id` (string, required): Domain UUID.

#### Example Request & Response
```json
// POST /api/student/domains/enroll
{
  "domain_id": "dom_quant"
}
```

```json
// Response 200 OK
{
  "success": true,
  "enrolled_at": "2026-06-17T12:00:00Z",
  "unlocked_concept_id": "con_quadratic"
}
```

## Key Components

- `/api/student/domains/route.ts`: Resolves listing requests.
- `/api/student/domains/enroll/route.ts`: Writes enrollment entries.

---

## Database Impact

- **Table `domains`**: Checked for validation references.
- **Table `subdomains`**: Mapped dynamically for concepts trees.
- **Table `progress`**: Initiates tracking progress records for newly enrolled students.
